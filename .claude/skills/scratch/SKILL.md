# Scratch

Follow the project `AGENTS.md` memory directives. This skill is a project-local shortcut; it does not override project instructions.

## Steps

1. Use `memory/scratch/` for project-only material that is not ready for today's note, `runs.md`, `learnings.md`, `decisions.md`, or `index.md`.
2. Keep `memory/scratch/index.md` as the routing guide.
3. Create or update one topic file per capture, using a clear lowercase slug such as `memory/scratch/dataset-consistency.md`.
4. Include the date, node/device if known, source paths, current question, evidence links, and next action.
5. Keep raw output out of scratch unless it is tiny; link to logs, artifacts, commits, or output paths instead.
6. Do not create or update today's project note for scratch-only exploration.
7. If the capture is already durable, skip scratch and write directly to the appropriate memory file.
8. If scratch work later produces a durable result, promote it to today's note and the appropriate structured memory file.
